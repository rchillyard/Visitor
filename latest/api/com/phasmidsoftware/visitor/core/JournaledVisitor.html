case class JournaledVisitor[V, R, J <: Appendable[(V, Option[R])]](journal: J, cameFromJournal: Option[CameFromJournal[V]] = ...) extends Visitor[V, R, J]

Canonical immutable implementation of Visitor.

Optionally carries a CameFromJournal for tracking came-from relationships. When cameFromJournal is non-empty, discover records (v, cameFrom) pairs. The start vertex is absent from the came-from map — it has no predecessor.

Use the factory methods on the companion object to construct instances.

Value parameters

cameFromJournal

optionally, a journal recording came-from relationships.

journal

the visit journal (ListJournal or QueueJournal).
