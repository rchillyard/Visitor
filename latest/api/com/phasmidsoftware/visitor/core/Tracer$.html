def summary[V](out: PrintStream = ...): Tracer[V]

A summary tracer that emits only top-level (depth 0) messages, using brief only — detail is never evaluated.

A summary tracer that emits only top-level (depth 0) messages, using brief only — detail is never evaluated.

Useful for a first look: students see only the major phases of the algorithm without the per-vertex noise.

Value parameters

out

the stream to write to; defaults to System.out.

def verbose[V](maxDepth: Int = ..., out: PrintStream = ...): Tracer[V]

A verbose tracer that indents output by two spaces per depth level and emits detail when non-empty, falling back to brief otherwise.

A verbose tracer that indents output by two spaces per depth level and emits detail when non-empty, falling back to brief otherwise.

Type parameters

V

the vertex type

Value parameters

maxDepth

only messages at or below this depth are emitted; defaults to Int.MaxValue (emit everything).

out

the stream to write to; defaults to System.out. Pass a custom PrintStream in tests to capture output without touching global state.
