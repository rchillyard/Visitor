ParentedVisitor

com.phasmidsoftware.visitor.core.ParentedVisitor
See theParentedVisitor companion object
case class ParentedVisitor[V, R, J <: Appendable[Mapped[V, R], J]](journal: J, evaluable: EvaluableFrom[V, R], parents: Map[V, V] = ...) extends Visitor[V, Mapped[V, R], J]

A Visitor that evaluates each node knowing the node it was first reached from.

It records predecessors as the engine discovers them and supplies them to an EvaluableFrom when the node is finally visited. This works because the engine calls discover(v, parent) before visit(v) for every non-start node — a contract pinned by VisitorOrderingSpec — so no change to Traversal is required.

First discovery wins, matching CameFromJournal: a node reached again by another route keeps its original predecessor. The start node has no predecessor, so it evaluates with None.

See issue #20.

// Which nodes were reached by a non-tree edge in an undirected graph?
val v = ParentedVisitor.withQueueJournal(using EvaluableFrom.parentOf[V])
